# 操作試作の読み方

[workspace.html](workspace.html) をブラウザーで開いて確認する。外部ファイルやチャットを参照しなくても、サンプルの画面操作を試せる。

## 参考にすること

- ホームの表形式の主一覧と、その外側の「いつか」欄。
- 一覧／詳細で共通の状態・サマリを編集する操作。
- 通常作成は未着手、ページ内の気づき作成はいつか。
- 資料目録の検索・種類／テーマの絞り込み・登録・共通情報編集。
- 資料から検討項目へ移動し、そのページの関連資料にも同じ登録情報が反映されること。
- 計画の最新予定・当初予定・実績の分離、基準保存、比較表示、報告画像のプレビュー。

## そのまま製品へ移さないこと

- 固定日付2026-11-03、配列によるデータ保持、ダミーのファイルパス・URL。
- 同名IDや配列長に依存する簡易処理、試作用の件数制限、ホスト状態保存。
- 縦に長い画面、列幅、詳細の開き方、すべての入力欄を常設する配置。
- 1テーマだけのサンプルを、製品の資料関連数の制約と解釈すること。

製品仕様との不一致は [確定仕様](../docs/next-app-spec.md) を優先する。製品で必要な機能のすべてが、この試作にあるわけではない。

## 限界

原本の起動、実ファイルの登録、DB保存、添付画像、アーカイブ、バックアップ・復元等は未実装。資料名のクリックは動作の案内だけで、サンプル原本を開かない。

画像コピーはブラウザーの権限や表示方法で利用できない場合がある。製品ではElectron側のクリップボード操作で実装する。コピー不可を成功扱いにしない。

単体版では外部CDNを使用しないため、チャット上で付いていた補助アイコンやホバー補助が省略される場合がある。文字ラベルと主要操作は利用できる。

## ソースと簡易確認

- `workspace.fragment.html`: 表示と操作の参考ソース。
- `workspace.html`: 単体で開ける書き出し版。参考資料であり、アプリのエントリーポイントではない。
- `../scripts/check-prototype.cjs`: Node.jsだけで動く簡易DOM検証。実ブラウザーの描画やWindows実機テストの代わりにはならない。

製品のソースはプロジェクトルートのsrc/等へ新規に作成する。prototype/配下をElectronから製品画面として読み込まない。
