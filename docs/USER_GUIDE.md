# Redia 操作ガイド

修正版 0.1.4／2026-11-07。利用中の改善を継続する。確認範囲と残る手動確認は [受入記録](ACCEPTANCE.md)、改修の手順は [継続改修](MAINTENANCE.md) を参照。

## 起動と保存

`release/win-unpacked/Redia.exe` を起動する。配布時には `win-unpacked` フォルダー全体を使用する。

入力は自動保存される。通常の保存状態は表示せず、失敗時だけ案内と再試行を表示する。終了はウィンドウの×で行う。保存できない場合は画面へ戻って入力を確認し、再試行する。異常終了後に復旧の案内が出た場合は、下書きを確認して復旧できる。

## ページ

HOMEの「新規ページ」、またはテーマを開いて「新規ページ」で、タイトルだけを入力して作成する。初期状態は未着手。作成画面は閉じ、元の一覧に残る。テーマは未所属でもよく、所属先は1つまで。

HOMEの主一覧には未着手・進行中・待ちが並ぶ。「いつか」は独立した欄。完了・中止はテーマの「完了・中止を含む」や検索から参照し、状態を戻せる。サマリは一覧から直接編集できる。期限と確認日は独立して設定する。

詳細はプロパティ、本文、関連資料、関連ページの順。本文で `# ` は見出し1、`## ` は見出し2、`- ` は箇条書きになる。書式操作は本文の右クリックメニューから行う。画像は貼り付け／選択で取り込める。

関連ページの「ページを追加」では、既存ページを検索・絞り込みして選べる。上部にタイトルを入力して新規作成すると、元ページのテーマと関連を引き継ぐ。

## 資料

「資料を追加」で、ファイル／フォルダー選択、パス／URLの貼り付け、登録済み一覧からの指定を行う。ページから開く一覧は、そのテーマで絞り込まれる。

貼り付けで取得したタイトルは登録前に修正できる。名前付きの共有リンクは、クリップボードに含まれる表示名とURLを使用する。URLだけからSharePointへ問い合わせる機能はない。同じ参照先が登録済みなら案内を表示し、既存の資料を再利用する。一覧右の「追加」「解除」で関連を切り替える。

資料タイトルをクリックすると原本を開く。種類欄など行の余白をクリックすると詳細が開き、タイトル・リンクと関連先別の用途メモを編集できる。関連ページ名からそのページへ移動できる。ページ内の用途メモは一覧で直接編集し、左のハンドルをドラッグして資料の順番を変えられる。

外部資料の原本はアプリへコピーせず、登録や関連解除で移動・改名・削除しない。本文に取り込んだ画像だけをアプリが管理する。

## 計画と報告画像

週・月ビューでは、未定行のカレンダーをクリックすると単日、ドラッグすると期間を指定できる。バーをドラッグして移動し、端をドラッグして期間を調整する。操作中のEscで取り消し、Ctrl+Zで元に戻す。

タイトル列の「+ New」で末尾へ追加、各行の左の＋で直下へ挿入する。タイトル列を閉じても最下段カレンダーから作成できる。行名やバーをクリックすると右に詳細が開き、左側の余白クリックで閉じる。ページとは独立した日程なので、ページの状態や期限は自動変更されない。

横ホイール・Shift＋縦ホイール・スクロールバーで左右へ移動する。Full HD・100%の目安は週約2週間、月約36〜40日、クオーター約3か月。クオーターではマウスの日程編集をロックし、詳細で日付を入力する。

「画像をコピー」で対象テーマ・期間・出力行とサイズを選び、「PNG画像をコピー」後にPowerPointへCtrl+Vする。画像は白背景で、タイトル列なし・バー上タイトルになる。実PowerPointへの貼り付けは、この環境では受入未確認。

## 検索・バックアップ・更新

Ctrl+Kでテーマ・ページ・資料を横断検索する。上下キーで選び、Enterで開き、Escで閉じる。外部資料の本文や画像内文字は検索しない。

設定からバックアップ先を変更し、手動作成・世代一覧・復元を操作できる。自動作成は30分ごとと正常終了時、完成済み30世代を保持する。DB・本文画像・復旧下書きを含み、外部資料の原本は含まない。復元では現在データを退避して再起動する。

配布版データは `%LOCALAPPDATA%/EngineeringWorkspace/production/`。更新時はアプリを閉じ、`win-unpacked` 全体を更新する。データ領域は保持する。利用中に見つかった改善点は、画面名・操作・期待した動き・実際の動きが分かる形で記録する。

2026-11-07／0.1.1更新: 計画は行高36px、文字14pxを維持し、長いタイトルはバーの右へはみ出して省略せず表示する（0.1.2で復元）。「今日」は現在の横スクロール位置を調整して今日を画面内へ移動する。テーマの資料一覧はページ経由の資料もドラッグでき、テーマ独自の順序を保持する。ページ内の資料順や用途メモは変わらない。


2026-11-07／0.1.3 計画の全テーマ表示: 「すべてのテーマ」を選ぶと、同じカレンダー上でテーマごとの見出しと配下の計画行を表示する。テーマの並びはサイドバーと同じで、グループ内は保存済み行順を保つ。未所属は末尾の独立したグループ。検索結果のないグループは出さない。個別テーマ／未所属のフィルターでは従来の見出しなし一覧とする。タイトル列を閉じた場合も、グループ名はカレンダー側に表示する。各行の「下に挿入」は元行のテーマを継承し、各グループ末尾の空行に「+ New」と空欄カレンダーを設け、そのグループのテーマを引き継いで追加する（0.1.4更新）。行の並べ替えは同一テーマ内、グループ間の移動は既存の詳細の所属テーマ変更で行う。ページのテーマや日付は自動変更しない。

2026-11-07／Redia 0.1.4: アプリ名称・ウィンドウ・左上表記・実行ファイル・インストーラー名をRediaへ統一する。内部appIdはjp.engineeringworkspace.desktop、保存先は従来の%LOCALAPPDATA%/EngineeringWorkspace/production/を維持し、既存データの継続を優先する。

全テーマ表示では各グループの最後に1行の空欄を置き、「+ New」で未定行、空欄カレンダーのクリック／ドラッグで日付付きの行をそのテーマへ追加する。タイトル列を閉じてもカレンダーから追加できる。未所属グループは未所属を継承。全テーマの通常の最下段空欄は各グループ末尾に集約し、計画が空の場合は未所属の作成欄を表示する。個別テーマ／未所属指定の末尾追加は従来どおり。

画像のコピー画面は、開いた時のテーマ・検索に一致する候補行と横スクロール位置／見えている期間を初期値にする。個別テーマ／未所属ではその行だけ、全テーマではテーマ見出しとグループ間の空欄を含めた画像を作る。テーマや期間・行選択は既存のプレビューで調整できる。原稿画像には「+ New」などの操作ボタンを入れず、バー上タイトル・白背景・日本語名の折り返しを維持する。
