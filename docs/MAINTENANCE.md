# 継続改修と残る実機確認

2026-11-07／初期版候補0.1.0。初期版候補の作成を仕様の凍結とは扱わず、利用しながら修正を続ける。新しいユーザー指示を仕様へ反映し、既存データ・関連・入力保護を維持する。

## 修正の進め方

1. 問題の画面・再現操作・期待／実際の結果、解像度・倍率を記録する。スクリーンショットに実資料の内容が入る場合は必要な範囲だけ共有する。
2. `test-artifacts/` の専用データで再現する。製品DBや原本で試さない。
3. 仕様・保存値・APIの変更が必要かを区別し、範囲に適したロジック／DB／操作試験を行う。見た目だけの修正でも該当する画面サイズを確認する。
4. README・仕様・DECISIONS・PROGRESS・ACCEPTANCEの必要箇所を更新する。未実施の検証は未確認として残す。
5. 別出力先で配布一式を生成し、起動中でないことを確認して通常配布先へ反映する。exe単体ではなくフォルダー全体を更新し、配布版の2回起動／終了と生成物の一致を確認する。署名・公開・自動更新は別途扱う。

## 自動確認

```powershell
pnpm typecheck
pnpm test
pnpm test:phase7
```

`test:phase7` は1366×768／1920×1080、Electron zoom100／125／150%、明暗の12条件で、HOME・テーマ・ページ・資料追加（単一／複数）・資料目録・計画・報告プレビューの8画面を確認する。画面外への横はみ出し、モーダル境界、資料追加の重なり・入力欄と一覧の到達性を検査し、96枚の画像と `layout-results.json` を `test-artifacts/phase7-*/` に出力する。Electron zoomはWindowsのOS倍率検証とは区別する。

保存・復旧・API・DBを変更したときは、関連する `test:phase1`〜`test:phase6` と `test:clipboard`／`test:focus`／`test:document-updates` も実行する。各試験の証跡はPROGRESSへ記録する。

```powershell
pnpm build
pnpm exec electron-builder --win nsis --x64 --config.directories.output=release/candidate
pnpm test:smoke:packaged
```

最後の起動試験は通常配布先 `release/win-unpacked/` を対象にするので、候補の反映後に実行する。現在の配布は未署名、選定済みのC案のRアイコン。NSIS生成成功はインストール／アンインストール確認の代わりにならない。

## 残る手動受入

自動試験では保存失敗・下書き・復元・原本保護を確認済みだが、以下を合格へ繰り上げない。今回Windows操作ツールの一覧にテスト用Electron窓が現れず、再取得でも対象窓を取得できなかった。製品データを使った代替試験は実施しない。

```powershell
pnpm test:phase7:manual
```

テーマ・ページ・資料・計画入りの専用環境を起動し、端末に `PHASE7_PROFILE` を表示する。Ctrl+Shift+F9で、このテスト窓だけDB書き込み障害を切り替えられる。正常な終了はウィンドウの×で行う。端末のCtrl+Cは強制終了になり得る。

同じ専用データを再起動する場合は、表示されたパスを指定する。再起動時にサンプルを追加し直さない。製品データの指定は拒否する。

```powershell
node scripts/phase7.mjs --manual --profile "test-artifacts/phase7-ここを実際の名前に置換"
```

| 対象 | 手順と期待結果 | 現状 |
| --- | --- | --- |
| A01：Windows IME | テーマ／ページ／関連ページの作成で変換中のEnterは確定だけ、次のEnterまたは作成操作で1件登録。本文の変換も確認 | 合成イベントは合格、実変換未確認 |
| A13：終了案内 | 書き込み障害中に編集して×。「戻る」で入力保持、障害解除後に再試行して保存。「下書きを残して終了」の経路は同じ専用プロファイルを再起動し復旧を確認。安全退避できない経路で終了を強行しないことも確認 | 自動保存・異常終了復旧は合格、ネイティブ全選択肢未確認 |
| A20：PowerPoint | 計画のPNGコピーを、新規の一時16:9スライドへCtrl+V。背景・文字・バー・長い日本語名と出力行を確認。利用中のスライドを上書きしない | PNG／コピーAPIは合格、実貼り付け未確認 |
| A22：ネットワーク | テスト用共有バックアップ先を切断／長時間無応答にする。並行してローカル閲覧／編集、終了待機上限と戻る／終了を確認。再接続後に再試行し完成世代を検証 | 保存先障害とローカル編集は合格、実UNC長時間停止未確認 |

| 配布 | テストPCでNSISを実行し起動・終了、既存データ保持とアンインストール範囲を確認 | 生成のみ合格、インストール・署名・更新未確認 |

未確認が残る間は「全受入完了」「Phase 7の完了条件達成」とは扱わない。次は実機手動確認と、利用中に再現した不具合・操作上の負担の修正を優先する。予定外の機能やプロパティは、この確認に紛れ込ませない。
